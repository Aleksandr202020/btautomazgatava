Ты — senior WordPress developer, PHP developer, UI/UX designer, SEO specialist и специалист по оптимизации WordPress.

Твоя задача — НЕ просто создать макет сайта, а разработать полностью рабочий production-ready WordPress-сайт для ручной автомойки BTAUTOMAZGATAVA.

Сайт должен быть реально устанавливаемым на обычный WordPress-хостинг Zone.lv без VPS, Docker и Node.js на сервере.

3. ТЕХНОЛОГИЧЕСКИЕ ТРЕБОВАНИЯ

Создать сайт как лёгкую собственную WordPress-тему.

Не использовать Elementor.

Не использовать WPBakery.

Не использовать тяжёлые page builders.

Предпочтительно:

- WordPress Block Editor / Gutenberg;
- PHP;
- HTML5;
- CSS3;
- Vanilla JavaScript;
- WordPress REST API только там, где действительно нужен;
- AJAX для онлайн-записи.

Совместимость:

- современный WordPress;
- PHP 8.x;
- MySQL/MariaDB;
- обычный shared hosting;
- Apache/Nginx;
- SSL/HTTPS.

Не требовать Node.js после установки.

Не требовать SSH.

Не требовать Docker.

Не требовать Composer на production-сервере, если без него можно обойтись.
